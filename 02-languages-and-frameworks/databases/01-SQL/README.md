# SQL Learning Path

Learn SQL from basics to optimization.

## 📋 Topics (In Order)

1. **01-basics.md** — SELECT, WHERE
   - Retrieve and filter data
   - Time: 3 hours
   - Practice: Basic queries

2. **02-join.md** — INNER, LEFT, RIGHT, FULL
   - Combine multiple tables
   - Time: 5 hours (most important!)
   - Practice: practice-1 and practice-2

3. **03-insert-update-delete.md** — CRUD
   - Add, modify, delete data
   - Time: 3 hours
   - Practice: practice-3

4. **04-transactions.md** — ACID, BEGIN, COMMIT
   - Multiple changes together
   - Time: 2 hours
   - Practice: Combine with other operations

5. **05-data-modeling.md** — Table design
   - Plan database structure
   - Time: 4 hours
   - Practice: Design practice-4

6. **06-indexes.md** — Speed optimization
   - Make queries faster
   - Time: 3 hours
   - Practice: Add indexes to practice databases

7. **07-optimization.md** — Query tuning
   - Use EXPLAIN, optimize queries
   - Time: 4 hours
   - Practice: Optimize slow queries from practice
