# Practice Databases

4 real-world database designs with exercises.

## 📋 Databases

### 1. practice-1-school.sql
**Scenario:** School management system

Tables:
- students (student_id, name, class, roll_no)
- teachers (teacher_id, name, subject)
- classes (class_id, class_name, teacher_id)
- marks (student_id, class_id, marks)

Exercises (10):
1. Find all students in class 10A
2. Find top 3 students by average marks
3. Find teachers with most students
4. ... (7 more)

**When to solve:** After learning JOIN

---

## 🎯 How to Use

1. Copy one database schema into your local database
2. Copy sample data
3. Solve 10 exercises
4. Check solutions
5. Move to next database

## 📊 Total Exercises

4 databases × 10 exercises = **40 total exercises**

## ⏱ Time Per Database

- Setup: 5 minutes
- Solve exercises: 2-3 hours
- Review solutions: 1 hour

Total: ~4-5 hours per database = **16-20 hours for all**
