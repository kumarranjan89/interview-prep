# Database Learning Guide

Learning SQL and NoSQL — structured, simple, practical.

## 📚 What's Here

- **01-SQL/** — SQL fundamentals to optimization
- **02-NoSQL/** — MongoDB, Redis, basics
- **03-Database-Comparison/** — SQL vs NoSQL, quick reference
- **04-Practice/** — 4 real-world practice databases
- **05-My-Project/** — Real project learnings
- **06-Quick-Reference/** — Cheatsheets and tools
- **notes/** — Progress tracking

## 🚀 Quick Start

Start with **01-SQL/README.md**

Follow this order:
1. 01-basics.md
2. 02-join.md
3. 03-insert-update-delete.md
4. Solve 04-Practice exercises while learning

- Oracle SQL Developer (free) OR
